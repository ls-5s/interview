# 腾讯前端算法&手写题终极完整清单（2026最新）

**合并两轮所有考点，按**出现频率+面试权重**严格排序，覆盖99%以上腾讯前端面试场次。难度以Easy-Medium为主，几乎不考Hard题。**

---

## ⭐⭐⭐⭐⭐ 5星必考题（每场必出，100%覆盖）

**腾讯核心特色：前端手写题优先级远超传统算法，一面必出1-2道，二面大概率再考进阶版，直接决定能否进入下一轮**

1. **Promise全家桶（最高频）**
   - 手写Promise A+规范核心
   - Promise.all/any/race/allSettled
   - Promise串行执行器、并发限制控制器
   - 手写async/await核心实现（基于Promise）
2. **防抖与节流**
   - 完整版本：支持`leading`立即执行、`trailing`延迟执行
   - 必备功能：`cancel`取消方法、支持返回函数执行结果
   - 必须能说出两者应用场景的本质区别
3. **深浅拷贝**
   - 完整深拷贝：处理循环引用、Date/RegExp/Function/Map/Set等特殊类型
   - 浅拷贝的5种实现方式及区别
4. **函数绑定与继承**
   - 手写call/apply/bind
   - ES5构造函数继承 vs ES6 class继承的区别与实现
   - 手写new操作符、手写instanceof运算符、手写Object.create
5. **数组原生方法实现**
   - 必考：`map`、`filter`、`reduce`（尤其是reduce）
   - 高频：`flat`（数组扁平化）、`forEach`、`some`、`every`
6. **柯里化**
   - 基础版 + 支持占位符 + 支持空调用的优化版（你之前写的基础版会被追问）
7. **事件总线（EventEmitter）**
   - 核心方法：`on`/`off`/`emit`/`once`
   - 进阶：支持事件命名空间、支持参数传递

## ⭐⭐⭐⭐ 4星高频题（80%场次会出现）

1. **数组与字符串处理（传统算法最高频）**
   - 必刷：两数之和、三数之和、版本号比较、大数相加
   - 常考：数组去重、最长公共前缀、最长回文子串
   - 核心技巧：双指针、哈希表、前缀和
2. **双指针技巧**
   - 快慢指针：环形链表检测、找链表中点、倒数第K个节点
   - 左右指针：二分查找、两数之和（有序数组）、反转字符串
   - 滑动窗口：最长无重复子串、最小覆盖子串
3. **链表**
   - 必刷：反转链表（单链表/部分反转）、合并两个有序链表
   - 常考：环形链表入环点、删除链表倒数第N个节点
   - 核心技巧：虚拟头节点、快慢指针
4. **二叉树**
   - 必刷：前/中/后序遍历（递归+迭代）、层序遍历
   - 常考：最大深度/最小深度、对称二叉树、最近公共祖先
   - 核心思想：递归、分治
5. **补充高频手写**
   - 手写深比较（isEqual）：处理循环引用和特殊类型
   - 手写URL参数解析（qs.parse）：支持数组、嵌套对象、特殊字符
   - 手写发布订阅模式
   - 手写JSON.parse/JSON.stringify核心逻辑

---

## ⭐⭐⭐ 3星常考题（50%场次会出现）

1. **栈与队列**
   - 必刷：有效的括号、用栈实现队列、最小栈
   - 腾讯高频：单调栈（每日温度、下一个更大元素）
2. **哈希表**
   - 很少单独出题，多作为辅助数据结构
   - 常见应用：字母异位词分组、统计频率、去重
3. **排序与搜索**
   - 必须掌握：快速排序（分治思想）、归并排序（稳定排序）
   - 必刷：二分查找及其变种（搜索旋转排序数组、查找插入位置）

## ⭐⭐ 2星低频题（20%场次会出现）

1. **动态规划**
   - 只考最基础的Easy-Medium题，几乎不考Hard
   - 必刷：爬楼梯、斐波那契数列、打家劫舍、最大子数组和
2. **位运算**
   - 必刷：只出现一次的数字、2的幂、位1的个数
3. **贪心算法**
   - 仅中高级面试偶尔出现
   - 必刷：跳跃游戏、分发饼干、买卖股票的最佳时机

## 🔥 腾讯特色必考题（单独准备，每年必考）

这些是腾讯所有部门都高频考察的特色题目，和通用算法题区分开：

1. **LRU缓存机制**（Medium，腾讯云、WXG最高频）
2. **数组转树形结构**（业务高频，PCG、CDG必出）
3. **手写响应式系统核心**（Vue3原理，全部门必考）
4. **手写虚拟DOM Diff算法同层比较核心逻辑**（React原理，中高级必问）
5. **大文件分片上传**（支持断点续传、进度条、并发控制）
6. **虚拟列表核心逻辑**（长列表优化，PCG/WXG高频）

## 🚀 二面三面专属进阶题（一面过了必看）

**一面几乎不会考，但二面三面出现率超过70%，是区分初级和中高级的关键**

- 手写带取消功能的Promise并发限制器（支持abort、优先级）
- 手写带指数退避的请求重试机制（超时、最大重试次数、错误过滤）
- 手写Promise串行执行器（支持传参、错误中断/继续）

### 2. 函数式编程

- 手写`compose`和`pipe`函数（Redux中间件、React高阶组件核心）
- 手写带缓存的`memoize`函数（支持过期时间、自定义缓存key）
- 手写惰性函数（环境判断只执行一次）

### 3. 框架原理进阶

- 手写Vue3 `ref`和`reactive`的核心区别实现
- 手写React `useState`/`useEffect`/`useMemo`/`useCallback`极简实现
- 手写简单的状态管理库（类似Zustand核心）

### 4. 性能与工程化

- 手写图片懒加载（基础版+IntersectionObserver优化版）
- 手写`fetch`的超时和取消实现
- 手写Web Worker通信封装

## ⚠️ 腾讯面试官最容易扣分的细节坑（90%的人会踩）

1. **所有手写题必须绑定正确的this指向**（写错直接扣一半分）
   - 重点注意：call/apply/bind、Promise的then方法、数组方法的回调函数
2. **必须处理边界条件**
   - 参数为`null`/`undefined`、空数组、空字符串、负数、0的情况
   - 写完代码一定要自己跑2-3个测试用例
3. **错误处理不能忘**
   - Promise必须处理reject
   - 函数参数做基本类型校验
   - 异步操作加try/catch
4. **不要过度炫技**
   - 腾讯面试官喜欢简洁清晰的代码，不要写一行流或过于复杂的语法
   - 先写核心逻辑，再优化细节
